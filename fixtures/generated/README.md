# Synthetic OHLC files for MSAS replay testing

These are 24 **synthetic** CSV files generated by `node scripts/qa/stress_qa.js` with seed `20261118` and 128 M15 candles, two for each of 12 volatility/trend regimes. They are neither exchange records nor hand-labeled Major/Internal truth. Upload any CSV using **+ Import** in the standalone HTML, or use `samples/normalized` for real sample regressions. The manifest holds deterministic per-file SHA-256 for safe comparison.

To regenerate the exact same examples from project root:

```bash
node scripts/qa/stress_qa.js --cases=360 --bars=128 --seed=20261118 --out=qa-artifacts/stress-report.json --emit-fixtures=fixtures/generated --fixtures=24
python -m unittest discover -s tests -p test_generated_fixture_manifest.py -v
```

**Do not overwrite real provider inputs with these fixtures.** The CSVs have no Volume column by design.
